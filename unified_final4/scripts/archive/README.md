# Archived Development Scripts

These scripts were used during development for one-off diagnostics, data probing, and auditing. They are no longer part of the active workflow and are kept here for reference only.

| Prefix | Purpose |
|--------|---------|
| `probe_*` | Ad-hoc data exploration and SQL probing scripts |
| `diag_*` | Diagnostic scripts for investigating specific stocks or CA events |
| `audit_*` | One-off audit comparisons (multi-version P&L, MV checks) |
| `verify_*` | Spot-verification scripts for view objects |

These scripts are **not maintained** and may not run against the current codebase. Do not rely on them for production use.
